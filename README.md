# SoundSpace — concept

A scroll-driven 3D product story for **SoundSpace**, a fictional headphone brand. The Aether over-ear tears down into its components, rebuilds, goes onto a head, and is joined by the Drift true-wireless bud and the Tether wired in-ear. The finish (Graphite, Glacier, Sage) can be switched at any point, even mid-transition.

Concept and design by Harshad Vaghasiya.

## Run locally
A single self-contained `index.html` (Three.js loaded from a CDN). Open it in a browser, or serve the folder with any static server.

## Stack
Three.js (r149), WebGL, custom GLSL shaders, vanilla JS/CSS. Models are embedded in the page as compressed mesh data.
